Customer support Assistant using SLM

Introduction:

The customer support assistant is an AI-powered chatbot developed using a SLM. It is designed to understand customer queries and generate helpful and relevant responses to common customer support problems.

Technologies used:
python
Hugging face 
SmolLM2-360M
PyTorch
VS code

Working procedure:
1. Load the SmolLM2-360M-Instruct model using the transformers pipeline.
2. Define a system prompt to establish the chatbot's customer support role
3. Accept customer messages through terminal input.
4. Combine the current messages with recent conversation history.

Conclusion:
This project demonstrates how a SLM can be used to develop a basic customer support chatbot. It provides practical experience in loading an SLM and generating responses maintainig conversation history an evaluating model behaviour.
